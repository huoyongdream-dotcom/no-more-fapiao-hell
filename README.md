# 发票登记表自动录入工具

把电子发票 PDF 自动抽取成发票登记表，省去手工录入。

## 文件说明

| 文件 | 作用 |
|---|---|
| `发票录入.command` | **双击运行**的入口（macOS，打开终端执行脚本） |
| `提取发票.py` | 主脚本：抽取字段、写入模板、生成登记表 |
| `发票登记表-模版.xlsx` | 登记表模板（8 列，无签名/验真伪/备注） |
| `发票待整理/` | 每次把要录入的新发票 PDF 丢进这里 |
| `发票待粘贴-日期/` | 处理完的 PDF 归档处（手动） |

## 使用方法

1. 把新发票 PDF（电子发票，带文字层）丢进 `发票待整理` 文件夹；
2. 双击 `发票录入.command`；
3. 自动生成 `发票登记表-YYYYMMDD.xlsx`（当天日期）到本文件夹；
   - 当天已有同名文件时，自动加序号：`发票登记表-20261124-2.xlsx`、`-3.xlsx`…不覆盖；
4. 核对无误后，把 `发票待整理` 里的 PDF 手动移去 `发票待粘贴-日期` 归档。

> 脚本只读 PDF，**不移动、不删除**你的文件。

## 字段口径（8 列）

| 列 | 说明 |
|---|---|
| 发票类型 | 取发票上的类型标签，如「电子发票（普通发票）」「铁路电子客票」 |
| 发票号码 | 20 位发票号码 |
| 开票日期 | 开票日期，格式 `2026年11月24日` |
| 开票单位 | 销售方（开票方）公司名，自动排除购买方 |
| 进项税率 | **百分比显示**（13%、6%、3%、1%，免税票显示"免税"） |
| 进项税额 | 金额 × 税率 ÷ (1+税率)，免税票为 0 |
| 货物或应税劳务、服务名称 | `*大类*明细`，如 `*交通运输服务*客运服务费` |
| 金额 | **价税合计（含税总额）**，取自发票上的中文大写金额 |

## 环境依赖

- Python 3，需安装 `openpyxl`（读写 Excel）、`pymupdf`（抽 PDF 文字）：

```bash
pip3 install openpyxl pymupdf
```

## 手动运行

```bash
python3 提取发票.py            # 正常录入：读 发票待整理
python3 提取发票.py --dry-run  # 只打印抽取结果，不写 Excel
python3 提取发票.py --input-dir <目录>  # 指定文件夹（测试用）
```

## 限制与注意事项

1. **只处理带文字层的 PDF**。拍照/截图的图片发票需 OCR，当前未做，遇到会跳过并提示。
2. **进项税额是"金额×税率"计算出来的**，不是从发票上直接抄的税额。正式报税前建议以发票原件为准核对。
3. **货物名称是弱项**：明细跨行时可能截断，或把"规格型号"混进去（如"电热水壶配件烧水壶"），建议扫一眼这一列。
4. 本工具假设购买方为律师事务所、销售方为"公司"结尾的商户（用于自动识别开票单位）。若你的购买方也是公司，需调整 `extract_seller` 里的匹配规则。
5. 产出是**初稿**，录入后请人工核对金额、税额、税率后再对外使用。
